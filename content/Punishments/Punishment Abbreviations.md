---
title: Punishment Abbreviations
---
When punishing someone, whether that be in-game or via the [[Game Link]], it is crucial to use the correct keyword so that the appropriate punishment is applied effectively.

In short, you don't need to manually type out your punishments and their respective duration. Simply executing a command along the lines of `/ban <user> <reason>` or `/mute <user> <reason>` will suffice.

> [!NOTE]
> Bans for `Administrative Ban` may only be issued at the discretion of an [[Administrator]]+

The list of ban / mute reasons includes:
#### Ban reasons:
- `Hacks` - Bans the user for unfair prohibited modifications
- `Doxxing` - Bans the user for doxxing another player
- `BanEvasion` - Bans the user for evading another punishment
- `InappropriateBuilds` - Bans the user for things like swastikas
- `MajorThreats` - Bans the user for major threats (e.g doxx threats)
- `BugAbuse` - Bans the user for abusing a bug they found
- `UnfairItems` - Bans the user for having unfair items in their kit

#### Mute reasons:
- `Slurs` - Mutes the user for saying a slur
- `Spam` - Mutes the user for spamming in chat
- `MinorThreats` - Mutes the user for minor threats (e.g "kys")
- `Toxicity` - Mutes the user for being overly toxic towards others
- `VoiceChatSpam` - Mutes the user for being loud in voice-chat
- `NSFW` - Mutes the user for discussing inappropriate topics
- `Advertising` - Mutes the user for advertising (can be anything)
- `Bugs` - Mutes the user for discussing bugs or glitches
- `Impersonation` - Mutes the user for impersonating a staff member
- `Filter` - Mutes the user for when they flag the chat filter
- `Doxxing` - Mutes the user for doxxing another player
